# SoloFit — контекст проекта

Описание для любого ИИ или нового человека. Прикладывай этот файл и только те файлы, которые нужно менять.

## Стек
- Статический сайт на GitHub Pages, чистый JavaScript, без сборщика.
- Supabase: регистрация, вход, подтверждение почты, таблица `solofit_data` (строка на пользователя, RLS).
- Cloudflare Turnstile: капча на входе и регистрации.
- Open Food Facts: онлайн-поиск продуктов (ODbL, источник указан в приложении).

## Файлы (все в одной папке, пути относительные)
| Файл | Что внутри | Что менять |
|---|---|---|
| `index.html` | Оболочка, главный скрипт: данные, питание, тренировка, синхронизация с облаком | только логику ядра (редко) |
| `auth.js` | Регистрация, вход, подтверждение почты, анкета (цель, параметры, опыт, активность), капча | экраны входа и анкеты |
| `nav.js` | Нижняя навигация: порядок, подписи, скрытие вкладок | состав и порядок вкладок |
| `profile.js` | Вкладка «Профиль»: аватар, имя, норма, параметры, выход | профиль |
| `support.js` | Вкладка «Поддержка»: FAQ и форма обращения | поддержку, почту |
| `theme.css` | Визуал | только стиль |
| `workouts.js` | База тренировок (верх/низ, HIT) | упражнения |
| `foods-core.js` | Встроенная база продуктов на 100 г | продукты |
| `foods-ru.js` | Продукты из Open Food Facts (генерируется `tools/import-off.py`) | не править руками |
| `foods-online.js` | Онлайн-поиск продуктов | поиск |
| `water.js` | Трекер воды (стакан 250 мл, 30 мл на кг) | воду |

Порядок загрузки в `index.html`: Supabase и Turnstile → `theme.css` → `foods-core.js`, `foods-ru.js`, `workouts.js` → главный скрипт → `auth.js` → `water.js`, `sleep.js`, `foods-online.js`, `profile.js`, `support.js`, `nav.js` (последним).

## Публичный API (`window.SoloFit`)
- `sb`: клиент Supabase. `isConfirm`: пришли ли по ссылке из письма.
- `getUser()`, `getGoal()`, `getDay()`, `getRoot()`, `save()`: данные пользователя и дня, сохранение в облако.
- `showApp(user)`: открыть приложение после входа и анкеты.
- `onAuth(fn)`: подписка на смену входа. `auth.edit()`: открыть экран параметров (из профиля).
- `onRender(fn)`, `onAppReady(fn)`: хуки перерисовки и входа.
- `addTab(id, label, html)`: новая вкладка внизу. `nav.setVisible(id, bool)`: показать или скрыть вкладку.
- `addFoods`, `addWorkout`, `renderFood()`, `renderWorkout()`, `selectFood(food)`.

## Модель данных
- Корень пользователя: `{ days: { "YYYY-MM-DD": { meals: {breakfast, lunch, dinner, snack}, sets: {индекс: [bool]}, water } }, sleep: { "YYYY-MM-DD": { from, to, q } }, profile: { name, avatar } }`.
- Запись приёма пищи: `{ name, g, kcal, p, f, c }`.
- Продукт: `{ n, b (бренд, необязательно), k, p, f, c }` на 100 г.
- Тренировка: `SOLOFIT_WORKOUTS.program.days[id].exercises` = `[{ name, sets, reps, group }]`, порядок `order`.
- Параметры (`user_metadata`): `name, goal` (weight_loss | fat_loss | muscle_gain | strength | maintenance), `height, weight, age, sex` (m | f), `activity` (sedentary | light | moderate | active | extreme), `experience` (beginner | intermediate | advanced).
- Облако: `solofit_data(user_id, data jsonb, updated_at)`. Локальная копия в `localStorage` нужна как запасной вариант без сети.

## Правила
- Визуал только в `theme.css`, тренировки в `workouts.js`, продукты в `foods-*.js`, экраны входа в `auth.js`, навигация в `nav.js`.
- Не класть секретные ключи в файлы. Публичный ключ Supabase уже в `index.html`. Секретный ключ Turnstile хранится только в настройках Supabase. Site key Turnstile вставляется в `auth.js`.
- Пути только относительные, все файлы в одной папке.
- Перед загрузкой проверять синтаксис JS (`node`).
